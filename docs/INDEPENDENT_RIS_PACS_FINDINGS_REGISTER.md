## Positive controls independently verified (no finding)
- **Password hashing:** argon2id + optional pepper (`auth.service.ts:37-49`). Sound.
- **Account lockout:** 5 failures → 15-min lock; generic "Invalid credentials" (no user enumeration) (`auth.service.ts:14-15,74-89`).
- **Refresh rotation + revocation:** old jti deleted on refresh, all revoked on logout/password-change (`auth.service.ts:122-162`). Sound.
- **JWT validate:** re-fetches user, checks `active`, rejects non-access tokens (`jwt.strategy.ts:44-51`).
- **RBAC guard:** AND-combined `@RequirePermissions`; routes without a decorator still require auth; super_admin bypass explicit (`permissions.guard.ts`). Module 4/5 OR-gate correctly enforced **in-service** (`operations-history.service.ts requireAnySource`, `operational-integration.service.ts overview/exceptions`).
- **Org isolation:** consistent `orgScope`/`assertOrg` across services; DICOMweb per-study + allowed-study filter (`dicomweb.service.ts:41-60`); Module 5 study aggregate returns **404 (not 403)** for cross-org (no existence leak).
- **Patient gating:** MRN only with `patient.view` across history/overview/exceptions/study; no-leak payload scans in tests.
- **Report immutability:** locked/FINAL → `ConflictException` on edit/re-sign/delete; addendum pattern (`reports.service.ts:208-212,297-298`).
- **search_tsv GIN:** created `IF NOT EXISTS`, trigger-maintained, **no DROP** in any migration (`0002_search_vector/migration.sql`); present in the live DB.
- **NGINX dynamic DNS:** `resolver 127.0.0.11 valid=10s` + variable upstreams intact (`nginx.conf:16`).
- **Archive integrity:** SHA-256 + gunzip + ZIP-entry re-verify; verified-archive overwrite protection; Module 4 re-verify is non-mutating (`archive.service.ts`).
- **Module 5 exceptions:** interrupted heuristic is non-mutating; recovery references existing endpoints only; no file-path/credential leakage (test-asserted).
- **Secrets:** `.env.example` holds placeholders only; `.env` is gitignored.
